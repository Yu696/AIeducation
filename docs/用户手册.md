# 爱教学 · 用户手册

> 项目：爱教学（教学质量全链路数字化管理平台）· 16 组
> 文档 Owner：余润东（产品与范围 / 验收）
> 适用版本：`v1.0.0-sprint3`

---

## 一、系统简介

爱教学是教学质量全链路数字化管理平台，围绕"课程—开课—教师—资源—备课—评教—听评课—排课"提供一站式查询与管理能力。系统内置五类角色，登录后按权限查看各自职责范围内的数据。

**核心价值**：让教学质量持续可测。

---

## 二、快速开始

### 1. 环境要求

| 项 | 要求 |
| --- | --- |
| JDK | 17（发布基线） |
| Maven | 3.9+ |
| MySQL | 8.0+ |
| 浏览器 | Chrome / Edge 最新版 |

### 2. 初始化数据库

```powershell
cd database
mysql -uroot -p123456 --default-character-set=utf8mb4 < schema.sql
mysql -uroot -p123456 --default-character-set=utf8mb4 < data.sql
```

> 注意：`data.sql` 非幂等，重复导入需先跑 `schema.sql` 重建库。

### 3. 启动后端

```powershell
cd backend
mvn spring-boot:run
```

> 离线/受限环境备选：`mvn -o -B compile` 后执行 `.\start.bat`。

### 4. 打开前端

浏览器访问 `http://localhost:8080/index.html`。

## 三、登录

1. 打开登录页，输入用户名与密码（演示账号密码统一 `123456`）。
2. 登录页底部有 6 个演示账号按钮，**点击即可自动填充**。
3. 登录成功后进入工作台；不同角色看到的工作台卡片与菜单不同。

| 账号 | 角色 | 可见范围 |
| --- | --- | --- |
| `admin` | 系统管理员 | 全量 |
| `director` | 教研室主任 | 本教研室（MATH） |
| `teacher1` / `teacher2` | 教师 | 仅本人 |
| `supervisor` | 教学督导 | 全校（只读为主） |
| `courseadmin` | 课程管理员 | 全校 |

> 出现「无权访问该功能」（403）是角色无对应权限的正确表现，不是故障。

## 四、主旅程（端到端演示路径）

以**教研室主任**账号为例，走通一条从登录到价值达成的完整链路：

1. 用 `director` / `123456` 登录 → 进入**主任工作台**。
2. 查看工作台统计卡片（课程/开课/教师/覆盖率/评教概览）。
3. 点击菜单「课程信息管理」→ 查看本教研室课程与开课情况。
4. 点击菜单「教学资源管理」→ 查看资源与备课视图。
5. 点击菜单「教学评价管理」→ 查看评教均分与学期趋势。
6. 点击菜单「督导覆盖率」→ 查看开课与督导覆盖情况。
7. 点击菜单「**排课统筹总览**」→ 按学期/教师/班级查看开课安排、上课时间地点（`scheduleInfo`）。【Sprint 3 新增】
8. 返回工作台，点「退出登录」。

> 教师、督导、课程管理员的旅程结构相同，只是可见数据范围不同（见表）。

## 六、排课统筹总览使用说明（US-11，Sprint 3 新增）

> 状态：页面已在 Sprint 3 实现（US-11，`main@40bd960`），以下为实际使用方式。

1. 进入「排课统筹总览」页面（`#/schedule`）。
2. 使用顶部筛选：**学期**、**教师**、**关键词**（课程/班级）。
3. 列表按"学期—教师—教学班"分组，展示：课程代码、课程名称、教师、班级、上课时间地点（`scheduleInfo`）、开课状态、学生人数。
4. `scheduleInfo` 为空时显示"**未填写**"，不报错。
5. 筛选无结果时显示空态提示。
6. 本页面为**只读**，不提供任何新增/修改/删除操作。

## 七、常见问题

| 现象 | 处理 |
| --- | --- |
| 前端 API 请求全部 401 | 先到登录页登录；刷新后需重新登录 |
| 请求 403「无权限」 | 当前角色无对应权限码，属预期；换对应角色账号 |
| 页面中文乱码 | 导入数据时加 `--default-character-set=utf8mb4` |
| `mvn test` 报数据库连接失败 | 测试库为 H2，检查 `backend/src/test/resources/application-test.yml` |
| 数据看起来"变少了" | `data.sql` 非幂等，按"先 schema 后 data"完整重载 |
| MySQL 连不上 | 启动 MySQL80 服务；检查 `application.yml` 口令 |
