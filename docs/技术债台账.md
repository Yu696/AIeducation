## 2. 带债发布前的确认门槛

1. TD-01 / TD-02 / TD-05 的“已知限制”必须写入 `docs/发布说明.md` 与 README，不得在演示中暗示已实现；
2. TD-03 必须归档最近一次真实 MySQL 冒烟日志，缺失则不得带债发布；
3. 任何新增债务先登记本台账，再由 DRI 与 PO 确认是否进入发布范围；
4. 影响正确性 / 安全性的新债一律不得带病发布。
