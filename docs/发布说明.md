## 1. 本轮交付概述

爱教学是教学质量全链路数字化管理平台。三个 Sprint 累计交付：

- **Sprint 1「查课程」**：课程、开课、教师统一数据建模与全量查询，四类角色登录与权限隔离。
- **Sprint 2「业务闭环」**：资源挂接、备课查看、评教分析、听评课状态机四条业务链 + CI/回归基线。
- **Sprint 3「收官发布」**：只读排课统筹总览（US-11）+ 发布工程收尾（T-02—T-07），把三个增量集成为发布就绪产品。

## 3. 本轮（Sprint 3）新增功能

### 3.1 US-11 排课统筹总览（只读）【已发布】

> 状态：**代码已合入 `main@40bd960`**；页面 `frontend/assets/js/pages/schedule.js` 与 `#/schedule` 路由已就绪，已通过 Release Checklist 并随 `v1.0.0-sprint3` 发布。

- **目标**：为教研室主任/教学督导/课程管理员提供一屏总览，按学期、教师、班级查看开课安排，展示课程、教师、班级、上课时间地点（`scheduleInfo`）原文。
- **实现方式**：复用现有 `GET /api/offerings`（已返回 `scheduleInfo` 并强制数据范围），前端新增只读页 `#/schedule`，**不新增后端接口、不改表、不做冲突检测**。
- **验收标准**：① 按学期/教师/班级查看开课总览；② 展示课程、教师、班级、`scheduleInfo` 原文；③ 支持筛选与空态；④ 不写入、不校验冲突、不改表；⑤ 不影响既有开课/课程/教师接口与回归。

## 4. 已知限制

| 限制 | 说明 | 影响 |
| --- | --- | --- |
| 排课总览为**只读** | 不做排课冲突检测、不写库、不改表 | 无法校验时间片/教室/教师冲突 |
| 评教趋势为**实时聚合** | 依赖 6 个 `idx_eval_*` 索引，无汇总表 | 教学数据量增长后需评估性能 |
| 冒烟依赖**本地 MySQL** | 未容器化（无 Docker/Testcontainers） | 冒烟需人工在本机执行 |
| API 契约**手工维护** | 未引入 OpenAPI/springdoc | 契约与实现一致性靠人工核对 |
| 前端图表存在少量重复代码 | `charts.js` 已收敛，残余轻微重复 | 无功能影响 |
